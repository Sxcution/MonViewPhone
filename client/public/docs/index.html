MonViewPhone - Docs

Tóm tắt nhanh
WS mặc định: ws://127.0.0.1:11000/

1) Khởi chạy

Thêm ?device=<udid> để chỉ mở 1 thiết bị hoặc ?ws=<url> để đổi endpoint. Tiles tự lấy danh sách từ tracker backend nếu có.

2) Lưới tile & điều khiển

  • Header: số thứ tự, udid, trạng thái. Nút ⠿ (kéo đổi vị trí), ↻ (reload), ⋯ (menu, viewer 👁).
  • Menu: reload, shell, file list, power/volume, screenshot, mở viewer tab riêng.
  • Thanh dưới: Back / Home / Recent.
  • Kích thước tile chỉnh ở cột phải (width), height tự tính theo tỉ lệ stream.
  • Kéo nút ⠿ sang tile khác để reorder (lưu localStorage: tileOrder).

3) Viewer (👁)

  • Mở từ menu tile, kéo bằng header, chỉ 1 viewer cùng lúc.
  • Overlay làm mờ tile gốc; đóng viewer trả config về global.
  • Cấu hình riêng (width, bitrate/FPS/bounds, khóa xoay) đặt trong cột phải khi viewer mở.
  • Tabs Files/Apps tái sử dụng stream sẵn có (không mở WS mới).

4) Cột phải

Kích thước tile

Slider width, height tự tính. Lưu localStorage.

Cấu hình stream

View width (viewer), Bitrate, FPS, Chiều rộng stream (height auto), Khóa xoay, Đặt lại mặc định. Khi viewer mở, áp dụng riêng thiết bị đó.

Điều khiển nhanh

Power, Vol +/-, Mute, Back, Home, Recent, Screenshot (device active hoặc nhóm sync).

Sync thiết bị

Bật/tắt sync, chọn device chính (radio), follower dạng lưới checkbox, dừng sync.

5) Sync

  • Bật sync → chọn main & follower trong cột phải.
  • Trạng thái lưu trong ActiveContext (localStorage syncAll, syncMain, syncTargets).
  • Tắt sync để điều khiển đơn lẻ.

6) Shell & File

  • Hash actions: #!action=shell&udid=... (Shell), #!action=list-files&udid=...&path=... (file listing).
  • Menu tile có mở shell/file list tab mới cho UDID đó.

7) Lưu cục bộ

localStorage: deviceDimensions, tileOrder, viewerWidthPx, sync*. Config viewer override chỉ tồn tại runtime.

8) Troubleshooting

  • Màn hình đen: kiểm tra WS backend, giảm bitrate/FPS, dùng nút ↻.
  • Không thấy thiết bị: thêm ?device=<udid> hoặc kiểm tra tracker WS.
  • Reorder không lưu: xóa localStorage tileOrder rồi reload.
